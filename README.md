# Модуль бронирования учебных аудиторий

Курсовой проект по ПМ.01, МДК.01.01 «Разработка программных модулей».
Тема 12: «Проектирование и разработка модуля бронирования учебных аудиторий».
Выполнил: Расулов Шохин Абдурауфович, группа ИСиП-23/1. Руководитель: Крючков Виталий Владимирович.

## Состав решения

| Проект | Назначение |
|---|---|
| `src/RoomBooking.Core` | Предметная область: «Аудитория», «Бронирование», интервал `TimeSlot`, доменная служба `BookingPolicy`, исключения `DomainException` и `BookingConflictException`. Не зависит от веб-платформы и базы данных |
| `src/RoomBooking.Web` | Веб-приложение ASP.NET Core Razor Pages: страницы, прикладные сервисы, EF Core + SQLite, JSON API |
| `tests/RoomBooking.Tests` | Модульные и интеграционные тесты NUnit (62 теста) |

## Возможности

- Справочник аудиторий: отбор по номеру, корпусу, назначению, вместимости, проектору; регистрация, изменение,
  вывод из эксплуатации с причиной и возврат.
- Бронирование на дату и время с проверкой пересечения заявок, рабочего времени 08:00–21:00, вместимости,
  срока (не в прошлом, не более 60 дней вперёд); при пересечении — список свободных аудиторий на то же время.
- Отмена бронирования с причиной до начала занятия; запись сохраняется в журнале.
- Расписание занятости всех аудиторий на день со шкалой и процентом загрузки; недельное расписание аудитории.
- Поиск свободных аудиторий на интервал.
- JSON API (`src/RoomBooking.Web/RoomBooking.Web.http`).

## Требования и запуск

- .NET SDK 10.0
- База данных SQLite `roombooking.db` создаётся автоматически при первом запуске по миграции
  и заполняется учебными данными.

```
dotnet run --project src/RoomBooking.Web
```

Адрес: http://localhost:5085. Тесты: `dotnet test`.

## Проверка

- `ci` — сборка и тесты при каждой отправке изменений;

- `docs/defects.json` — дефекты, найденные при проверке кода этапа 3, и их исправление.
