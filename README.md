# Модуль бронирования учебных аудиторий

Курсовой проект по МДК.01.01 «Разработка программных модулей».
Тема 12: «Проектирование и разработка модуля бронирования учебных аудиторий».

## Состав решения

| Проект | Назначение |
|---|---|
| `src/RoomBooking.Core` | Предметная область: классы «Аудитория», «Бронирование», правила проверки данных (DomainException) |
| `src/RoomBooking.Web` | Веб-приложение ASP.NET Core Razor Pages, хранение данных в SQLite через EF Core, JSON API |

## Этап 2 (текущий)

- База данных SQLite `roombooking.db` создаётся автоматически по миграции `CreateRoomsAndReservations`.
- Сопоставление классов с таблицами задано через Fluent API (`Data/BookingContext.cs`), номер аудитории уникален.
- Каталог аудиторий с отбором по номеру, корпусу, назначению, вместимости и наличию проектора.
- Регистрация и изменение аудитории; вывод из эксплуатации с указанием причины и возврат в эксплуатацию.
- Подготовлена таблица бронирований `Reservations` (функции бронирования — этап 3).

## Запуск

```
dotnet run --project src/RoomBooking.Web
```

Адрес приложения: http://localhost:5085
