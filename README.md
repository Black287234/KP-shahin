# RoomBooking — модуль бронирования учебных аудиторий

Курсовая работа по МДК.01.01 «Разработка программных модулей».
Тема № 12: «Проектирование и разработка модуля бронирования учебных аудиторий».
Выполнил: Расулов Шохин Абдурауфович, группа ИСиП-23/1. Руководитель: Крючков Виталий Владимирович.

**Этап 1 — планирование и первый запуск.**

## Состав решения
| Проект | Назначение |
|---|---|
| `src/RoomBooking.Core` | доменный слой: сущность «Аудитория» и правила проверки данных |
| `src/RoomBooking.Web` | веб-приложение ASP.NET Core Razor Pages и JSON API |

## Требования
- .NET SDK 10.0 (`dotnet --version` → `10.x.x`);
- любой современный браузер.

## Запуск
```powershell
dotnet run --project src/RoomBooking.Web
```
Адрес: http://localhost:5085. Остановка — `Ctrl+C`. В Visual Studio: открыть `RoomBooking.sln`, проект запуска — `RoomBooking.Web`.

## Проверка
| Адрес | Ожидаемый результат |
|---|---|
| `/Rooms` | каталог из 6 учебных аудиторий |
| `/Rooms/Card/1` | карточка аудитории А-101 |
| `/Rooms/Card/999` | страница «Запись не найдена» (код 404) |
| `/api/rooms` | JSON-массив аудиторий |
| `/api/rooms/999` | `{"error":"Аудитория с идентификатором 999 не найдена"}`, код 404 |

## Хранение данных
На этапе 1 данные хранятся в оперативной памяти (`Infrastructure/InMemoryRoomCatalog.cs`) и сбрасываются при перезапуске.
